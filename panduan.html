📖 Panduan Resmi Pengguna Publik
Panduan Memulai & Mengoperasikan SIMGK Deiyai
Selamat datang di pusat bantuan SIMGK Deiyai (Sistem Monitoring Gereja Koordinator Deiyai, Papua Tengah). Halaman ini menyajikan tutorial visual langkah demi langkah agar Anda dapat memahami seluruh alur pelayanan dengan mudah dan cepat.

⛪
1. Galeri & Foto Gereja

👥
2. Manajemen 3.847+ Jemaat
Penyaringan multi-kolom (kelasis, status, gender), ekspor CSV cepat, serta impor massal file JSON.

🔑 1. Cara Masuk Sistem & Memilih 3 Akun Demo

Sistem dapat dieksplorasi langsung tanpa registrasi menggunakan 3 akun demo resmi:

Peran Pengguna Email Login Password Cakupan Hak Akses

💡 Langkah Cepat: Buka Halaman Login (login.html), klik kotak akun demo yang diinginkan, form terisi otomatis, lalu klik tombol Masuk ke Sistem →.
⛪ 2. Manajemen Gereja & Melihat / Mengunggah Foto Gereja
1
Melihat Banner Foto Gereja (Showcase Detail)
Buka menu Gereja, klik tombol mata 👁️. Modal detail akan menampilkan foto arsitektur gereja beresolusi tinggi dengan informasi nama gembala, tahun berdiri, jumlah jemaat, dan alamat.
2
Menambahkan Gereja & Unggah Foto
Klik tombol ＋ Tambah Gereja. Masukkan identitas gereja dan pilih foto gereja dari galeri komputer/HP Anda (maks 2MB). Pratinjau foto akan langsung tampil.
3
Penyimpanan Persisten Otomatis
Foto otomatis tersimpan permanen di LocalStorage browser dan tidak akan hilang saat me-refresh halaman.
👥 3. Manajemen Data Jemaat, Filter & Impor/Ekspor
1
Pencarian & Penyaringan Multi-Kolom
Gunakan filter Kelasis, Status (Aktif / Pindah / Meninggal), Jenis Kelamin, dan kolom pencarian untuk menemukan jemaat secara instan.
2
Ekspor CSV & Impor JSON
Klik tombol ⬇ Export CSV untuk mengunduh rekap jemaat atau ⬆ Import Data untuk memasukkan data massal file JSON.
📅 4. Pencatatan 9 Jenis Kegiatan Ibadah & Kehadiran

Sistem memfasilitasi pencatatan 9 kategori ibadah: Ibadah Minggu, Ibadah Pemuda, Ibadah Wanita, Sekolah Minggu, Baptisan, Pernikahan, Dukacita, Seminar, dan Pelayanan Sosial.

✓ Sinkronisasi Grafik: Setiap penambahan kegiatan otomatis mengupdate diagram batang kegiatan bulanan di Dashboard secara real-time.
📋 5. Laporan Pelayanan & Alur Persetujuan (Approval)
1
Pengiriman oleh Admin Kelasis
Admin Kelasis mengirimkan laporan bulanan, tahunan, atau kegiatan dengan status awal ⏳ Proses.
2
Persetujuan Resmi oleh Super Admin
Super Admin memeriksa isi laporan dan mengklik tombol centang hijau ✓ untuk mengubah status menjadi ✓ Diterima.
💾 6. Pencadangan (Backup) & Pemulihan (Restore) Database

Pada menu Pengaturan (Super Admin), Anda dapat mencadangkan seluruh kelasis, gereja, foto, jemaat, kegiatan, laporan, dan akun ke satu file JSON (Backup_SIMGK_Deiyai_YYYY-MM-DD.json) serta memulihkannya kapan saja via tombol Restore Backup.

❓ 7. Pertanyaan yang Sering Diajukan (FAQ)
Q: Apakah saya harus login untuk membaca panduan ini?
A: Tidak. Halaman panduan ini dapat dibaca langsung oleh siapa saja dari halaman utama (Landing Page) tanpa perlu login terlebih dahulu.
Q: Bagaimana jika saya ingin langsung mencoba aplikasinya?
A: Silakan klik tombol "🚀 Masuk Sistem →" di pojok kanan atas, lalu pilih salah satu dari 3 Akun Demo yang tersedia.
