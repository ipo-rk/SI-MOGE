Pusat Bantuan & Panduan Pengoperasian Dashboard

Panduan lengkap ini membantu Anda menjalankan seluruh proses kerja di dalam sistem SIMGK Deiyai, mulai dari input data jemaat, unggah foto gereja, pencatatan kegiatan, alur persetujuan laporan, hingga pencadangan database.

Versi 3.5 Final ✓ Persistent LocalStorage ✓ Cross-Tab Realtime Sync ✓ Showcase Foto Gereja
🔑 1. Autentikasi & Hak Akses 3 Peran Pengguna

⛪ 2. Manajemen Gereja & Unggah / Lihat Foto Gereja (Showcase Detail)
1
Melihat Foto & Profil Gereja (Modal View)
Buka menu Gereja, klik tombol mata 👁️ pada baris tabel gereja. Modal detail akan muncul menampilkan Banner Showcase Foto Gereja beresolusi tinggi beserta nama gembala, tahun berdiri, jemaat, dan alamat.
2
Menambahkan Gereja & Unggah Foto
Klik tombol ＋ Tambah Gereja. Isi data gereja dan pilih foto gereja dari perangkat lokal (maks 2MB). Pratinjau gambar akan otomatis tampil.
3
Penyimpanan Persisten
Foto dikonversi ke format base64 dan tersimpan permanen di LocalStorage browser.
👥 3. Manajemen Data Jemaat, Filter & Impor/Ekspor JSON/CSV
1
Penyaringan Multi-Kolom
Gunakan filter Kelasis, Status (Aktif / Pindah / Meninggal), Gender, dan pencarian nama pada menu Jemaat.
2
Ekspor CSV & Impor Massal JSON
Klik ⬇ Export CSV untuk unduh data jemaat atau ⬆ Import Data untuk upload berkas JSON.
📅 4. Monitoring Kegiatan & Pencatatan 9 Jenis Ibadah

Mencatat 9 jenis kegiatan: Ibadah Minggu, Pemuda, Wanita, Sekolah Minggu, Baptisan, Pernikahan, Dukacita, Seminar, dan Pelayanan Sosial pada menu Kegiatan. Grafik bulanan akan otomatis ter-update.

📋 5. Laporan Pelayanan & Alur Persetujuan (Approval Workflow)

Admin Kelasis membuat laporan (⏳ Proses). Super Admin memeriksa dan menyetujui laporan via tombol centang hijau ✓ menjadi (✓ Diterima) pada menu Laporan Pelayanan.

💾 6. Pencadangan (Backup) & Pemulihan (Restore) Database

Super Admin dapat mengunduh backup database JSON pada menu Pengaturan via tombol 🔄 Backup Sekarang dan memulihkannya kembali via tombol ♻️ Restore Backup.
